Baseline scope

This predictor is intended as a transparent, reproducible reference model rather than a final clinical or experimental decision system.

Cross-domain limitation: experiments revealed substantial distribution shift between different data sources. Predictions for molecules from unseen patent or experimental domains may therefore be unreliable.
Classification convention: SIF samples with a mapped half-life of at least 270 minutes and SGF samples with a mapped half-life of at least 250 minutes are treated as relatively stable.

Dataset construction and access

Two task-specific files are produced from heterogeneous patent-derived stability records using explicit mapping, filtering, and provenance-preservation rules.

Dataset overview

The dataset contains monomeric peptides collected from multiple original CSV sources. Patent or source identifiers are preserved in the source_name field so that users can inspect provenance and construct source-aware evaluation protocols.

From raw records to trainable data

The original records use heterogeneous stability representations. The processing pipeline converts them into task-specific, minute-based datasets suitable for machine-learning experiments.

1. Task-specific fields

SIF uses SIF_minutes, while SGF uses SGF_minutes. The two tasks are filtered independently.

2. Valid half-life values

Samples with missing or invalid values for the selected task are removed.

3. Monomer filtering

Only records satisfying is_monomer = True are retained.

4. Range filtering

The recommended construction protocol retains samples with task half-life values no greater than 700 minutes.

5. Provenance preservation

source_name records the original raw file or patent source for leakage checks and source-aware splitting.

6. Task-ready fields

The final files retain SMILES, the existing class label, the minute-based half-life, and source information.

SIF and SGF are independent tasks. A sample that lacks a valid half-life value for one task may still be retained for the other task.

Label mapping rules

The mapping below converts heterogeneous labels from the original collected records into a common minute-based scale. This enables comparison across sources but introduces discretization effects, so small performance differences should be interpreted cautiously.

Task Main fields Stable threshold Current distribution
SIF SMILES, SIF_class, SIF_minutes, source_name ≥ 270 minutes 336 short / 179 long

Existing SIF_class and SGF_class values may originate from different labeling systems. For unified binary classification, regenerate labels from the minute fields and use one consistent threshold rule throughout training, validation, and testing.

Molecular representations

The benchmark includes 24 basic physicochemical descriptors. Approximately 220 extended RDKit descriptors are additionally available as the MolDescriptor representation.

Charge statistics

Mean, maximum, minimum, standard deviation, and sum of molecular Gasteiger atomic charges.

QED-related properties

Molecular weight, lipophilicity, hydrogen-bond counts, polar surface area, rotatable bonds, aromatic rings, and structural alerts.

Basic physicochemical descriptors

MolWt, LogP, HBA, HBD, TPSA, ring count, Fsp3, heavy-atom count, and total atom count.

Rigidity indicator

A coarse rigidity index combines ring and aromatic counts relative to the number of rotatable bonds.

Data-quality note

In the currently merged historical files, two SIF records contain half-life values above 700 minutes: 816 and 2100 minutes. Both originate from US9809623B2.csv. No corresponding SGF records above 700 minutes were identified.

Strict reproduction of the stated filtering protocol should exclude these two SIF records or regenerate the task files from the raw-data cleaning pipeline.

Benchmark motivation

A unified resource for peptide-stability modeling, source-aware evaluation, and limited target-domain supervision.

Why this benchmark matters

The main contribution of this work is not a new predictive architecture, but the formulation of SIF/SGF stability prediction as a benchmark with explicit data boundaries, task definitions, and source-generalization protocols.

The resulting resource provides a unified foundation for model comparison, cross-source robustness research, and learning under limited target-domain supervision.

Research focus

Unified task definitions

Explicit SIF and SGF task boundaries reduce ambiguity when comparing models across studies.

Source-aware evaluation

Preserved provenance supports evaluation under realistic cross-source distribution shifts.

Reproducible baselines

Fixed representations, splits, thresholds, and metrics provide a transparent reference point.

Limited target supervision

The benchmark supports studying adaptation when only a small amount of target-domain data is available.

Resources

The dataset, implementation, and interactive prediction service are provided as separate but connected resources.
